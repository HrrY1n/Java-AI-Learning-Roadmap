# 产品与设计决策

## 核心产品边界

首版围绕 Stage 01 的一次真实学习：回到当前任务 → 理解课程 → 预测与修改 → 独立写 Java → 本地运行 → 复盘。首页任务来自学习执行计划；14 Stage 来自统一路线；学习证据只进入浏览器数据，不修改仓库进度。后续阶段提供真实资料入口，不生成空课。

依赖范围：新建 web 应用、生成内容、数据与服务契约、本地验证 CLI、自动化测试、文档。原课程和个人练习均只读。没有云端帐号、在线 Java 或付费模型依赖。

## 两种方向比较

| 维度 | A 暖纸工作室（选用） | B 夜航终端 |
| --- | --- | --- |
| 原创性 | 书页边注、细线、章节编号与深蓝工作台建立识别 | 终端窗口、网格与荧光强调，容易接近现有开发工具 |
| 产品适配 | 阅读与写代码有自然分区 | 更偏代码，对长篇中文不够亲切 |
| 层级 | 大标题、章节线、稀疏功能色 | 多窗格与密集状态文字 |
| 阅读 | 暖白、较大行高、限制正文宽度 | 深底长文需要更多调校 |
| 练习 | 独立深海蓝编辑区，导师按需展开 | 默认多栏挤压编辑器 |
| 响应式 | 侧栏转抽屉，阅读与练习自然叠放 | 多窗格转换成本较高 |
| 动效/性能 | CSS 短过渡，无装饰图像 | 终端动效价值有限 |
| 一致性 | 相同标注、字阶和边线跨五页复用 | 编程页强，路线页较难统一 |

选择 A，保留 B 的专业编辑区。仅借鉴代码随想录的章节顺序和知识联系，不采用其布局、品牌和资产。参考：[代码随想录](https://programmercarl.com/)。

## Design tokens

- Light：暖纸底 `#f5f4ef`，白纸面 `#fffefa`，石墨字 `#202c31`，深海蓝 `#143b49`，苔绿强调 `#c5e99c`。
- Dark：墨绿底 `#111c20`，抬升面 `#18272c`，暖灰字 `#e6eae4`，柔绿强调；边线和代码背景单独定义，不反相。
- 功能色：成功绿、警告琥珀、错误砖红；所有状态同时有图标/文字，不仅靠颜色。
- 中文使用系统无衬线（Microsoft YaHei / PingFang SC）；英文 system-ui；代码 Cascadia Code / SFMono-Regular / Consolas。无付费字体与远程字体请求。
- 字号：阅读正文 16px，行高 1.95；题干 15px；页面标题约 29–48px，随视口收敛；辅助导航与标签 10–13px，纯英文编号使用更小字阶；编辑器 15px / 25px。
- 间距以 4px 为单位，主要区块 32/40px；圆角 8/12/18px，仅主要学习卡使用较大圆角。
- 阅读栏最大约 760px，shell 侧栏约 240px；实验室使用剩余完整宽度，编辑器高度至少 480px。

## 交互与适配

桌面固定导航，平板窄导航/可展开课程，手机抽屉与底部主导航。实验室在窄屏上下排列，手机默认轻量 textarea，始终可输入并有语法预览。导师为受焦点约束的对话框，Escape 关闭并归还焦点。练习默认 TODO 骨架，参考源码需明确主动解锁并记录。

过渡为 120–220ms 的 opacity/transform/color，输入不等待动画；`prefers-reduced-motion` 禁用非必要过渡。键盘有可见焦点，跳到正文入口，按钮触控区域至少 44px。正文代码块允许自身横向滚动，页面不可溢出。

## 风险与约束

浏览器本地数据不是跨设备同步，需备份；存储拒绝和损坏必须明确报错。Java 编辑器不具备 JDK；仅手动 CLI 运行自己的代码，不能部署为服务器。证据 JSON 是用户自持运行记录，哈希绑定源码但不是不可伪造的证明。源码文档中的矛盾需要就地说明，不能静默改题或声称全部自动判题。
