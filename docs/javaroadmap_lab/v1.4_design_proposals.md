# JavaRoadmap Lab V1.4 导航与视觉设计提案与选型论证

本文档记录 JavaRoadmap Lab V1.4 专题学习体系升级过程中的导航、信息架构与视觉交互设计方案，重点对比两套高保真设计方案，并给出选型结论。

---

## 一、业界优秀设计模式研究

本轮设计借鉴并融合了现代前端与技术文档领域的三大代表性规范：

### 1. Fumadocs 设计模式
- **核心特征**：专为深度技术文档与工程学习构建的现代化结构，强调高密度信息排版的清晰感与快速全局检索。
- **借鉴要素**：
  - **顶部全宽导航栏**：包含全局快速检索触发器（`⌘K` / `Ctrl+K`）、主题切换（浅色/暗色/跟随系统）与主技术栈分支选择器。
  - **三列式宽屏布局**：左侧多级折叠目录树、居中正文主体（控制在 72ch-85ch 最优阅读宽度）、右侧页面内动态大纲（Scrollspy TOC）。
  - **视觉层次**：1px 微妙描边（`border-subtle`）、去卡片化的大背景融合、状态圆点与微型徽标（Badge）。

### 2. Astro Starlight 设计模式
- **核心特征**：极简、快速、强可访问性（a11y）的技术手册架构，擅长处理多层级章节群组。
- **借鉴要素**：
  - **语义化面包屑（Breadcrumbs）**：清晰指引 `主线 > Stage 01 > Day 04 循环` 或 `专题 > Hello 算法 > 02 复杂度分析`。
  - **分类组头（Group Heading）与状态标识**：严格区分「核心教程」、「深入讨论」、「动手实验」，并用文字徽章标注「已发布」、「建设中」。
  - **上下页导引（Prev/Next Pagination）**：文末提供前后知识点直达跳转，维持连贯学习心流。

### 3. shadcn/ui 视觉设计模式
- **核心特征**：中性、克制、高质量的现代组件库，排斥多余装饰与花哨渐变，注重间距、字体缩放与边框细节。
- **借鉴要素**：
  - **Command Dialog（全局命令与检索面板）**：支持键盘光标穿梭，分章节分组呈现实时检索匹配。
  - **Tabs 胶囊与分段控制器**：用于在「课程讲解 / 最小代码 / 观察预测 / 独立练习」之间无缝切换。
  - **统一图标规范**：统一采用 `lucide-react`，尺寸规范为 16px（行内辅助）与 18-20px（导航主项），线宽固定为 1.75px，严禁随意混杂不规范的 Emoji 或外部第三方图标库。

## 二、两套设计方案对比与规格定义

两套方案均采用真实课程数据（如 Stage 01 变量与循环、Stage 02 面向对象基础、Hello 算法复杂度分析与链表、Pro Git 基础与分支），并保留既有的「暖纸底色（Warm Paper）」与中性暗色模式。

### 方案一：专业文档阅读式布局（Documentation-Centric Layout）
- **定位**：技术手册与深度阅读优先，全站以多级文档树为主干。
- **页面构成**：
  1. **桌面首页**：Docs 风格 Landing Page，提供快速开始、核心路线总览卡片、专题入口卡片。
  2. **移动端首页**：顶栏汉堡菜单抽屉，单列流式卡片，直接进入各章节阅读。
  3. **Java 主线课程目录**：左侧展示 Stage 01 ~ Stage 03 展开树，点击即刻在主体区域渲染文档。
  4. **算法专题目录**：独立算法专题文档树（复杂度分析、线性结构、树堆图、高级算法）。
  5. **Git 专题目录**：Git 工程化指南文档树（起步、基础、分支、高级工具、内部原理）。
  6. **正文阅读页**：大篇幅阅读器，右侧附带小标题大纲（TOC），底部折叠收纳代码实验面板。
  7. **全局搜索界面**：文档全文检索 Modal，高亮标题与正文段落。
  8. **学习记录入口**：顶部右上角设置或次级抽屉中查看掌握进度与备份管理。

### 方案二：学习工作台与专题目录融合式布局（Learning Workbench & Topic Hybrid Layout）
- **定位**：学习闭环优先，将「看懂原理（文档）」与「动手写代码（实验室）」、「预测运行（验证）」、「学习进度（工作台）」融为一体。
- **全新一级信息结构（5 大支柱）**：
  1. **学习工作台（Workbench）**：展示当前正在进行的 CURRENT 任务、每日打卡心流、近期复习推荐、多设备状态。
  2. **主线课程（Core Tracks）**：Java 基础、OOP、核心能力（Stage 01 ~ 03），清晰显示阶段与模块结构。
  3. **专题学习（Topic Hub）**：数据结构与算法（Hello 算法）、Git 工程实践（Pro Git），以及预留的计算机底层专题（CSAPP、操作系统、计算机网络，清晰标明资料索引状态）。
  4. **编程实验室（Code Lab）**：多文件 Java 练习、输入用例、代码编写、本地 JDK 指纹证据导入验证、预测改动题。
  5. **学习记录（Records & Review）**：已掌握章节、反思笔记、验证证据流、无损 JSON 备份导入导出。
- **交互特征**：
  - 桌面端：顶部全局 5 支柱 Tab + 实时搜索；左侧动态随所选支柱自适应切换为对应的多级章节导航（可一键收起/展开，支持纯粹阅读模式）；中间支持「阅读模式」与「研读+代码双栏对照模式」。
  - 移动端：底部固定 5 支柱导航栏，点击专题或课程时从底部弹出半屏 Sheet 进行章节快速换选，单手操作极佳。

## 三、五维严谨评估与选型

| 评估维度 | 方案一：专业文档阅读式 | 方案二：学习工作台与专题融合式 | 优胜方案 | 选型分析 |
| :--- | :--- | :--- | :---: | :--- |
| **1. 信息架构清晰度** | 结构层级深，练习和复盘藏于文档末端，学习闭环动作不够显眼。 | 5 大支柱分类清晰：学什么（主线/专题）、在哪练（实验室）、学得怎么样（工作台/记录）一目了然。 | **方案二** | 学习不同于纯查阅 API，需要频繁在读与练之间切换，方案二架构更具行动力。 |
| **2. 阅读体验** | 专例文档流，右侧大纲优秀，长篇阅读极为沉浸。 | 同样具备面包屑、大纲与可收起侧边栏，并提供专注阅读模式，排版间距与对比度一致。 | **平手** | 两者均吸纳了 Fumadocs/Starlight 的排版优点，排版宽度和字号阶梯一致。 |
| **3. 移动端操作** | 依赖深层折叠汉堡菜单，多层级点击跳回成本高。 | 采用原生 App 级的底部 5 支柱导航 + 触底抽屉，大拇指单手触达率 100%。 | **方案二** | 方案二移动端切换主线、专题与记录极其顺畅，无迷失感。 |
| **4. 扩展性** | 当后续加入算法 15 章、Git 10 章、操作系统等，左侧树极其冗长，滚动负担大。 | 专题独立成 Hub，按书目分类分页签（已发布 / 持续建设 / 资料索引），主线与专题互不干扰。 | **方案二** | 方案二能优雅承载未来的 CSAPP、OSTEP 等而不影响当前 Java 主线。 |
| **5. 视觉一致性** | 偏向经典开源文档站，色调中规中矩。 | 延续暖纸（Warm Paper）设计语言，组件边缘处理更加现代，配合统一 Lucide SVG。 | **平手** | 统一采用同一套设计令牌与图标规范，视觉质感均达到发布级标准。 |

### 选型结论
**综合决定将「方案二：学习工作台与专题目录融合式布局」作为 JavaRoadmap Lab V1.4 的默认正式实施方案。**
同时，在前端保留可视化原型预览路由（`#/prototype`），供双方案 8 个界面的直观比对与验收追溯。
