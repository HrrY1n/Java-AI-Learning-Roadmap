# 本地数据与服务边界

## 数据模型与保存

浏览器 IndexedDB 数据库 `javaroadmap-lab` 的 `learning` object store 保存单个 `snapshot`。模型版本为 `schemaVersion: 1`，包含课程阅读位置、草稿、提示等级、预测作答、复盘、源码关联实测记录、参考答案查看记录与主题。阅读位置用 0–1 的比例表示；它不表示掌握程度。

每次保存使用一次原子事务写入完整快照，承诺成功必须等事务完成。模块把保存排队，避免快速编辑时较旧内容晚到覆盖较新草稿。独立 `revision` 键检测另一标签页的写入；检测到冲突时拒绝覆盖，提示先导出当前内容、刷新后合并。存储失败、权限阻挡、空间不足或数据损坏均抛出可显示的错误，不把失败说成“已保存”。损坏的已有快照不会在读取时被自动清空。

`LearningState` 类型与实现位于 `web/src/lib/learning-store.ts`。网站数据只存当前浏览器和当前站点来源；切换端口、浏览器、设备或删除站点数据后不能自动恢复。定期导出备份；浏览器本地存储不能替代个人长期备份。

## 导出、合并与恢复

导出为 UTF-8 JSON，保存整个版本化快照。导入前检查版本、必需与未知字段、日期、类型、ID、危险键、条目数与长度。单份备份上限 10 MB；每类最多 500 条，单份草稿上限 1,000,000 个字符。未来版本会被拒绝，保留原文件后使用相应版本恢复；不会猜测迁移。导入界面应先展示内容概况，并要求明确选择合并或替换；替换前应先导出原记录。

合并规则：按每条 `updatedAt` 保留较新的课程、草稿、预测和复盘；同一时间保留本机当前记录。提示取最高已查看等级，参考查看记录取较晚时间。实测记录按 ID 去重；同 ID 不同内容会取消合并并要求分别保留备份。合并不会把作答次数相加，以免同一备份重复导入虚增次数。合并保留一份较新草稿，不保留同题全部历史版本；不同设备的重要版本应另存源码或备份。网站从不写入 `真实学习进度.md`。

## 预测判定

`checkPrediction` 只归一 CRLF/CR 为 LF、每行末的空格或 Tab，以及最后一次换行。它保留行首空白、内部空行和输出顺序。不执行 Java；判断成功只说明这一次预测与题目确定答案一致。修改题保留文字预测和复盘，涉及设计选择时不作伪自动判题。

## Java 实测记录

`Evidence` 使用源码 UTF-8 字节的 SHA-256，与当前练习 ID 和当前草稿逐字匹配。每条记录保存 JDK 版本、命令、时间、测试输入、预期输出、真实 stdout/stderr、退出码与断言结果。导入时重新核对用例结果和总体结果是否与输出、比较方式和退出码一致。编译失败和超时必须保存为失败记录。执行工具采用精确输出比较；服务契约额外保留 `contains` 比较类型，只有明确只验证片段的后续适配器才使用。

这些是用户本地可编辑的实测记录，**没有数字签名，不是防篡改认证**。指纹用于避免把旧版本运行结果关联到新草稿。通过只适用于记录中列出的断言；单个用例通过不代表整题验收，更不代表 Stage 完成。查看参考答案独立记录；它不能被转换成“独立完成”。

## 可替换执行器与导师

`web/src/lib/services.ts` 提供：

- `JavaExecutor`：接收练习 ID、源码、输入与取消信号，返回真实 stdout/stderr、退出码与源码指纹。
- `localExecutor`：`available: false`，调用时明确说明没有在线沙箱，提示使用本地 JDK。没有假运行或假通过。
- `TutorService` / `courseTutor`：同步课程提示、五步 Debug 引导、P0–P4 Review 清单。它不分析或重写用户代码，也不冒充实时 AI。
- `ModelTutorService` / `unconfiguredModelTutor`：异步真实模型契约；未配置时拒绝调用。

首版不提供网络代理、云沙箱或真实模型调用。接通时由受控后端实现认证、限流、超时、取消、费用预算、日志脱敏与错误处理；密钥只保存在服务端。执行未知 Java 必须使用隔离环境，不把本地执行工具暴露为公网接口。课程上下文与源码只在用户明确启用服务时发送，禁止把 API Key 放进前端构建变量或备份。
