# JavaRoadmap Lab 交付文档

JavaRoadmap Lab 将当前仓库的 Stage 01 课程与独立练习接入本地学习产品。主线仍由[学习执行计划](../../学习执行计划.md)决定，14 Stage 以[统一学习路线](../../统一学习路线.md)为准，学习状态仍以[真实学习进度](../../真实学习进度.md)记录的证据为准。

## 启动与使用

从仓库根进入 `web/`，使用 Node.js 22.12 或更新版本运行：

```text
npm ci
npm run dev
```

默认访问 [http://127.0.0.1:5173](http://127.0.0.1:5173)。Windows / macOS、构建、测试、数据迁移和静态托管的完整命令见[网站 README](../../web/README.md)。本次交付不自动部署公网。

## 产品边界

当前可学习范围为 Stage 01：6 个基础课、7 个概念深化课、8 道确定性输出预测、4 道修改任务与4个结构化编程练习。后续阶段展示真实知识地图与已有资料，不批量生成未来课程。

学习工作台、路线、课程阅读、编程实验室和复盘共享本地状态。阅读、独立尝试、使用提示、查看参考与实际运行案例分别记录。网站不会自动上调 Stage 状态，不读取或改写 `my_practices/`，也不会向权威进度文档写入完成项。

Java 在自己的 JDK 中手动运行，网站导入与当前源码匹配的实测记录；没有在线执行环境时不会显示假运行结果。课程提示、Debug 引导与 Review 清单无需模型服务；真实模型、云沙箱、认证与云同步为后续有条件接入能力，当前没有网络代理或密钥配置。

“已实现”和“已验证”以[验收记录](validation.md)逐项区分；启动指令、接口或适配说明本身不等于相关环境已经测试。截图与正式审计材料统一归入本目录，生成测试缓存和临时输出不进入 Git。
