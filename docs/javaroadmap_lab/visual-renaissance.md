# JavaRoadmap Lab · V1.1 视觉再生（Visual Renaissance）

日期：2026-10-31　分支：`codex/visual-renaissance`　基线：main @ b3627b7

本轮是纯视觉重设计：不新增功能、不改课程内容、不动持久化 schema、不改路由与 URL。改动范围：`web/src/styles.css`（token 重写 + 再生层）、`web/src/App.tsx`（眉标文案与导航小字）、`web/index.html`（theme-color）、`web/public/favicon.svg`（品牌色对齐）。

## 1. 改版前审计（真实截图见 renaissance/before-*.png）

1. **英文微型标签过密**：每页都有等宽英文 kicker（YOUR LEARNING SPACE / THE BIG PICTURE…），导航、页脚、卡片各有英文小字，层次碎、模板感强。
2. **构图同质**：所有页面都是"侧栏 + 顶栏 + 居中卡片列"，同一节奏复制到全部九类页面。
3. **首页深色大块孤立**：深绿 hero 与下方白卡片的关系生硬。
4. **实验室题目文字墙**：任务背景/输入/输出/约束挤成连续段落，缺视觉分段；移动端 tab 截断。
5. **品牌识别度弱**：暖白+深绿好读但不可记忆；无签名元素。

## 2. 方向探索与选型（探索稿存 `.audit-work/design-explore/`，截图见同目录 shots/）

三个方向各产出桌面首页+阅读页代表稿，按七维评分（1–5）：

| 维度 | A 现代数字学院 | B 创意学习工坊 | C 精密开发者工作室 |
| --- | --- | --- | --- |
| 原创性 | **5** 中文讲义排版+印章红，罕见 | 3 常见教育风 | 4 |
| 阅读舒适度 | **5** 纸白长文最稳 | 3 装饰偏多 | 3.5 暗底长文易疲劳 |
| 长时间使用 | **5** | 3 | 4 |
| 交互质量 | 4 | 4 | **5** 面板语言最配 IDE |
| 响应式 | 4 悬挂边注需降级 | **5** | 4 |
| 实现成本 | 4 | 4 | 3.5 |
| 未来扩展 | **5** 行式条目加课零成本 | 4 | 4 |

**决策：以 A 为骨架，融合 C 的面板镀铬与等宽数字体系；B 不采纳**（原创性与长期阅读弱，仅吸收其进度可视化的轻量手法）。理由：本产品本质是"读讲义 + 写代码"——A 解决占时长最长的阅读，C 的镀铬语言解决实验室与编辑器；两者共享同一套纸面 token，不产生双语系。

## 3. 设计系统（实现于 styles.css「V1.1 VISUAL RENAISSANCE」层 + :root tokens）

**色彩**：纸白 `--paper #f7f6f1`、卡面 `--surface #fffefb`、墨黑 `--ink #21201b`；唯一强调色**印章红** `--accent #b5432c`（暗色换赤陶红 `#dd8168` 保持印章语义）。语义色 success/warning/error 降为辅助。深色主题整体为"夜间讲义"：暖黑纸面 + 同一版式。

**字体**：中文界面一律系统无衬线（PingFang/雅黑栈）；**等宽字体只承担三类职责**——编号（01/02…）、代码、状态词。英文微型标签全部退场。

**签名元素**（可复用规则）：
1. **眉标**：2px 印章红短线 + 中文标题字距 0.22em + 等宽编号（`.eyebrow`，新增内容时直接复用）。
2. **章节双线**：主要区块标题上缘 2px 墨线（`.section-title`/`.group-label`/`.lesson-heading`）。
3. **巨大等宽序号**：任务/阶段/指标用 mono 数字表达（`.task-number`/`.stage-index`/`.evidence-metrics strong`，tabular-nums）。
4. **样张代码窗**：首页 code specimen 与 `.code-block` 共用"纸面卡 + 红点文件名"镀铬；hljs 配色随主题（关键词=印章红）。
5. **标题句号印章**：`h1 .heading-period` 为印章红。

**组件规则**：按钮=胶囊（主=墨色、强调=印章红、次=细线）；徽章=细线胶囊 mono；卡片=1px 细线 + 10–14px 圆角 + 极轻阴影，hover 才浮起；列表行=细线分隔 + hover 染纸，选中=左缘 3px 红条；对话框=纸面 + 背景压暗模糊；焦点环=2.5px 印章红。

**动效**：仅两类——hover 边缘着色/上浮 2px、进入 reveal（6px 上移渐显）；`prefers-reduced-motion` 下全部禁用（沿用既有断言，e2e 已覆盖）。

**对比度**：全部文本经 axe WCAG AA 扫描（6 视口 × 双主题 × 6 页面 = 12 组）零违规；`--faint`/`--muted` 灰阶为满足 4.5:1 重新校准，层级改由字号与字重承担。

## 4. 各页面的构图差异（不再是同一卡片复制）

- **工作台**：刊头（眉标+巨标题+边注式 CTA）→ 样张代码窗 → 学习环 → 双栏任务/边注 → 入口条。
- **路线**：分组双线标题 + 阶段行（巨大序号）+ 右侧详情卡。
- **课程阅读**：双线刊头 → 阅读进度标尺 → 步骤节（红 § 序号+细线）→ 右缘"本节脉络"边注目录。
- **练习**：下划线 tab + 题签 radio-card + mono 输入区。
- **实验室**：文件 tab 镀铬 + 题目卡（列表项细线左缘、强调词红标）+ 编辑器/输出面板；编辑器尺寸未缩小。
- **复盘**：等宽指标墙 + 左缘红条提示 + 证据行。
- **文档**：只读讲义版式（notice 红左缘）。
- **对话框/抽屉/空态**：同一纸面语言。

## 5. 扩展规范（新增 Stage 02/03 课程时遵守）

1. 新课程/练习/文档直接进入 catalog，版式自动继承；**不要新增页面级 CSS**，优先复用上文签名元素。
2. 颜色只允许使用 `:root` token；需要新语义色时先加 token 再用。
3. 英文只允许出现在代码、mono 编号与品牌名；界面文案中文优先。
4. 新区块标题用 `.section-title`（或 `.group-label`），行式列表用细线行 + mono 序号模式。
5. 深色主题零额外成本的前提：不写死十六进制背景色，全部走 token。

## 7. 已知限制

- 字体维持系统栈（未引入 webfont）：不同系统下中文 display 字重略有差异，属有意取舍（零外部依赖、Pages 离线可用）。
- `.code-illustration` 首页样张在深色主题下与卡面同为深底，对比略平（可接受，避免为对比引入新色）。
- Monaco 编辑器内部配色未深度定制（保持默认高亮），仅外框镀铬统一。
