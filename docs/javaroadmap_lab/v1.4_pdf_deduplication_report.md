本报告记录 JavaRoadmap Lab V1.4 专题建设过程中，对外部只读教材资料库（`D:\Code\计算机好书\books`）进行安全解析、知识点去重、版权隔离与课程来源追溯的具体实施。

## 一、外部资料库只读合规与安全边界

1. **只读合规原则**：
   - 本地资料库 `D:\Code\计算机好书\books` 属于外部独立只读数据源。
   - **严禁**将原书 PDF、整本提取的全文文本或第三方版权图片提交至公共 GitHub 仓库。
   - **严禁**在公开的代码和元数据中暴露本机特定绝对路径。
   - 正式课程内容全部基于知识点原创编写，Java 教学代码由项目组全新实现并经过编译验证。
2. **长 PDF 分阶段安全处理机制**：
   - **阶段一（元数据与大纲）**：通过物理书签和目录索引提取章节树与物理 PDF 页码范围。
   - **阶段二（去重与映射）**：对照现有 Stage 01~03 课程进行重叠度审查，剔除机械重复，聚焦补充深度。
   - **阶段三（按需局部阅读）**：借助 `books.py read <book> --section <id> --count 2~4` 按小节精确调阅原文概念定义与边界描述，单次调阅上下文严格限制在 4 页以内，杜绝整书灌入上下文。
   - **阶段四（原创内容研发）**：采用 `Scenario → Why → Concept → Mental Model → Minimal Code → Observe → Modify → Exercise → Real Usage` 教学模型全新重构，附带原创 ASCII / SVG 图解与 Java 源码。
   - **阶段五（全量自动化验证）**：编译运行 Java 示例，在临时沙箱中执行 Git 实验，通过多平台回归。

## 三、知识点去重与深度补充分析

### 1. 《Hello 算法》与现有 Java 基础/核心课程的去重分析
- **重叠排查**：
  - Stage 01 的 `day04_loop` 和 `day05_array` 讲解了 Java 循环语法与一维数组声明。若《Hello 算法》再机械地讲一遍“如何在 Java 中定义数组”，属于低效重复。
- **差异化补充定位**：
  - 算法专题跳出纯语法层面，深入至**物理内存连续性、寻址公式推导（$Base + i \times S$）、插入/删除数据搬移代价（$O(n)$）以及 CPU 缓存友好度**。
  - 将算法效率评估从感性的“运行跑表测速”上升到理论的**渐近时间/空间复杂度分析（大 O 阶梯）**。
  - 栈与队列部分补充了数组环形指针模运算机制（解决假溢出问题）及经典括号匹配算法。

### 2. 《Pro Git》与现有工程线材料的去重分析
- **重叠排查**：
  - Stage 08 早期示例仅包含简单的脚本打印命令，缺乏交互式状态流转与图解。
- **差异化补充定位**：
  - 系统建立**快照流（Snapshot Stream）vs 增量差异（Delta）**的核心心智模型。
  - 严密解析工作区（Working Dir）、暂存区（Index）与仓库历史（HEAD）的三大状态机流转。
  - 拆解 Fast-Forward 快进合并与三方合并（Three-way Merge）的双父提交结构，辅以严格的一次性沙箱实验。

### 3. 《On Java 8》与主线课程的去重与现代演进分析
- **完全重叠（Full Overlap）**：基本运算、控制流语法与常规 for/while 循环，现有课程已完备，仅提供原书章节作为辅助查阅。
- **深度扩展（Extension）**：类与对象从“定义语法”上升到原书的“对象是微型服务提供者”职责切分；继承部分强化“组合优于继承”的软件设计权衡。
- **缺口补充（Gap Supplement）**：接口解耦策略、多态动态绑定后期分派机制、散列码（hashCode 与 equals）强一致契约。
- **现代 JDK 演进纠偏**：
  - 明确标注 JDK 8 原书中未出现的特性：局部变量类型推断（`var`，Java 10）、增强型 Switch（`->` 与 yield，Java 14）、Record 数据载体类（Java 16）、密封类与接口（Sealed Classes，Java 17）、try-with-resources 自动资源管理。
  - 警示不要沿用已废弃的历史类（如 `java.util.Date` / `Calendar`，应使用 Java 8+ 的 `java.time.*`）。
