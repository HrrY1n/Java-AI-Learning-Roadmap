# I/O 设备、中断、DMA 与 RAID

## 1. Scenario：从一个具体问题出发
磁盘顺序读写与随机读差异巨大；RAID 0 和 RAID 5 的取舍不同。

## 2. Why：为什么这个问题值得系统理解
设备速度、中断、DMA 和冗余方式共同决定 I/O 成本和可靠性。

## 3. Concept：核心概念
设备通过寄存器/队列交互，中断减少轮询，DMA 批量搬运数据。RAID 用条带化提高吞吐，镜像或奇偶校验提高容错。

## 4. Mental Model：把机制装进一张图
`应用 I/O -> OS 驱动 -> 设备协议 -> 磁盘/SSD`；RAID 在块层提供不同容量/冗余折衷。

## 5. Minimal Code：最小示例
```text
随机小写 -> 寻道/擦除成本高
顺序大写 -> 吞吐更稳定
```

## 6. Observe：先预测，再运行
用模拟器计算 RAID 0 和 RAID 1 在 4 块盘、1 个故障时的容量与可用盘数。

## 7. Modify：只改一个有意义的条件
把条带宽度或副本数改掉，比较理论容量和可承受故障数。

## 8. Exercise：独立完成
设计一个纯教学 RAID 容量计算器，明确它不测量真实磁盘性能。

## 9. Real Usage：联系 Java 与工程实践
数据库、日志和文件存储要区分吞吐、延迟和故障恢复成本。
