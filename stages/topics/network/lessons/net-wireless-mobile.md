# 无线与移动网络：WiFi、蜂窝与移动切换

## 1. Scenario：从一个具体问题出发
移动设备切换网络后 TCP 连接中断；应用需要重连策略。

## 2. Why：为什么这个问题值得系统理解
无线链路误码、竞争和移动性会造成吞吐波动与连接变化。

## 3. Concept：核心概念
802.11 使用接入点与 MAC 机制；蜂窝网络涉及 LTE/5G 架构；移动性需要在归属/被访网络间路由。高层协议要容忍连接变化。

## 4. Mental Model：把机制装进一张图
`无线介质 -> 接入点/基站 -> 核心网 -> 互联网`；移动切换可能改变路径。

## 5. Minimal Code：最小示例
```java
NetworkInterface nic = NetworkInterface.getByName("lo");
System.out.println(nic != null ? nic.getDisplayName() : "lo 不存在");
```

## 6. Observe：先预测，再运行
在桌面环境查看回环接口；不要断开真实 WiFi 做破坏性实验。

## 7. Modify：只改一个有意义的条件
在纸上画两条时序线：通信对端把包发给归属代理再转发（间接路由），与对端直接发给转变后的地址（直接路由）。标出设备移动后的每一步，比较两条路径的跳数与切换期间的丢包窗口。

## 8. Exercise：独立完成
设计一个移动设备断线重连策略：指数退避、幂等请求与会话恢复。

## 9. Real Usage：联系 Java 与工程实践
移动端后端必须处理网络切换、延迟抖动和证书/域名校验。
