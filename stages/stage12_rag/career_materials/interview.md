# 面试常见问题与参考回答

> 以下是旧路线留下的入门参考，不是背诵答案。请在完成对应阶段后，用自己的代码、失败案例和取舍重新回答。

## Python 基础

**问：列表和字典有什么区别？**  
答：列表按顺序存放多个元素，适合遍历；字典用 key-value 存放数据，适合按字段查询。

**问：为什么要用函数？**  
答：函数可以复用逻辑，让代码更清晰，也方便测试和修改。

## Git

**问：git add 和 git commit 的区别？**  
答：`git add` 把修改放入暂存区，`git commit` 把暂存区内容保存为一次提交记录。

## Linux / PowerShell

**问：常用命令有哪些？**  
答：`pwd` 查看当前目录，`ls` 列出文件，`cd` 切换目录，`mkdir` 创建目录。

## API

**问：GET 和 POST 有什么区别？**  
答：GET 常用于查询数据，POST 常用于提交数据或创建请求。

## RAG

**问：RAG 是什么？**  
答：RAG 是检索增强生成，先从文档中检索相关片段，再把片段和问题一起交给模型生成回答。

## Embedding

**问：Embedding 的作用是什么？**  
答：Embedding 把文本变成向量，让系统可以用相似度计算找到相关内容。

## Top-k

**问：Top-k 检索是什么意思？**  
答：从所有候选片段中选出得分最高的 k 个片段，作为回答依据。

## Prompt

**问：Prompt 模板为什么重要？**  
答：模板能稳定组织角色、任务、上下文和输出格式，让回答更可控。

## Streamlit

**问：为什么用 Streamlit？**  
答：它适合快速做 Python 数据和 AI Demo，不需要学习复杂前端。

## FastAPI

**问：FastAPI 在项目里做什么？**  
答：它把 RAG 能力封装成 HTTP 接口，方便其他系统调用。

## SQL

**问：SQLite 可以用来做什么？**  
答：可以保存问答历史、评测记录和简单项目数据。

## 项目介绍

**问：请介绍你的 RAG 项目。**  
答：我的项目面向论文和专利文档问答，使用 Python 实现文档读取、文本切分、Top-k 检索、Prompt 拼接和回答生成，并用 Streamlit 做了页面，用 FastAPI 提供接口，还补充了问答质量评测报告。
