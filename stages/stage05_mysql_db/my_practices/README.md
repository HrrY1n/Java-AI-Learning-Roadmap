# my_practices：我的独立练习区（Stage 05 MySQL）

1. 先复制 [db.local.properties.example](../db.local.properties.example) 为同目录的 `db.local.properties`（已被 `.gitignore` 忽略，指向你的隔离测试库），或配置环境变量 `JRL_MYSQL_URL` / `JRL_MYSQL_USER` / `JRL_MYSQL_PASSWORD`。
2. **严禁把测试脚本指向你的其他个人数据库或生产库**（测试脚本会重置演示表）。
3. 独立任务说明见 [practice/s05_lab_tasks.md](../practice/s05_lab_tasks.md)。
