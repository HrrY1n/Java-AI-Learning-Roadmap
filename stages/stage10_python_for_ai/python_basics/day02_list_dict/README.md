# day02：列表、字典、循环与论文元数据

## 今天学什么

- 用 list 保存多条数据；
- 用 dict 表达结构化对象；
- 遍历列表和字典；
- 按关键词筛选论文；
- 统计关键词出现次数。

## 为什么对 AI/RAG/Python 实习有用

RAG 系统经常要处理“文档列表”“检索结果列表”“API 返回 JSON 列表”。列表和字典是这些数据的基础形状。

- 能用 dict 表示一篇论文；
