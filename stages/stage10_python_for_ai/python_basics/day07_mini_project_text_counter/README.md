# day07：小项目 - 文本/Markdown 文档统计器

## 今天学什么

你会把 Stage 10A 前六天的知识组合起来，做一个完整小项目：

- 读取 txt/md 文件；
- 统计字符数、单词数、行数、段落数；
- 统计关键词频率；
- 输出 Markdown 报告；
- 用 `utils.py` 拆分工具函数；
- 处理文件不存在和空文本。

## 为什么对 AI/RAG/Python 实习有用

这是后续 RAG 项目的前置能力。真正的 RAG 系统在切分、检索、问答之前，必须先能读取文档、理解文档规模，并输出可检查的处理报告。

- 能解释 `main.py` 和 `utils.py` 的分工；
- 能生成 `output_report.md`；

- 能为自己的 txt/md 文档生成统计报告。
