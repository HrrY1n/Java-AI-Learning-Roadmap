# Python 基础：教学模式课程

## 这一阶段的目标

这一阶段不是为了背语法，而是为了用 Python 完成真实小任务。你会从变量、字符串、列表、字典、函数、文件、JSON、CSV、异常处理开始，逐步过渡到一个能输出 Markdown 报告的文本统计小项目。

## 为什么它和 AI/RAG 实习相关

后续 RAG 项目需要你经常处理：

- 论文标题、摘要、关键词；
- 用户问题和 Prompt 模板；
- 文档片段和检索结果；
- JSON API 返回内容；
- CSV 报告；
- txt/md 文件读取；
- 程序报错和异常处理。

Stage 10A 的前 7 天会把基础语法放进这些场景里练。

## 三层训练

- 基础层：看懂语法，知道变量、循环、函数、文件怎么用。
- 应用层：自己补全 TODO，完成文本处理、统计、格式化输出。
- 项目层：把多个知识点组合成一个可运行的小工具。

## 每天文件结构

每个 day 目录都包含：

- `README.md`：当天目标、用途、运行命令、完成标准。
- `main.py`：带注释的完整示例。
- `practice.py`：3-5 个基础练习，保留 TODO。
- `challenge.py`：1-2 个更接近真实任务的进阶练习。
- `debug_task.py`：故意写错的代码，用来训练 debug。
- `expected_output.md`：运行结果对照。

当前目录没有单独的 `notes.md`。学习错误、验证命令和复盘统一记录到根目录 [真实学习进度](../../../真实学习进度.md)，不要为了匹配旧说明批量制造空笔记。

## 建议学习方式

1. 先读当天 `README.md`。
2. 运行 `main.py`，确认示例能跑。
3. 打开 `practice.py`，按 TODO 补代码。
4. 挑战 `challenge.py`。
5. 运行 `debug_task.py`，根据报错自己修。
6. 对照 `expected_output.md`。
7. 在根目录 `真实学习进度.md` 写下今天最容易错的地方、验证命令和下一步。
