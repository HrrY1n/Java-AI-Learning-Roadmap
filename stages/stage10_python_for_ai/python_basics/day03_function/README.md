# day03：函数、参数、返回值与文本处理工具

## 今天学什么

- 定义函数；
- 参数和返回值；
- 把重复逻辑封装成函数；
- 返回结构化 dict；
- 生成简单 Prompt。

## 为什么对 AI/RAG/Python 实习有用

RAG 项目本质上是一组函数的组合：读取文档、清洗文本、切分文本、检索片段、构造 Prompt、生成回答。函数写得清楚，项目才容易扩展。

```powershell
python .\stages\stage10_python_for_ai\python_basics\day03_function\practice.py

```

## 完成标准

- 能写至少 3 个函数；
- 能区分 print 和 return；
- 能让函数返回 dict；
- 能构造一个包含上下文和问题的 Prompt。
