# day01：变量、字符串与学习日报输出

## 今天学什么

- 变量命名和赋值；
- 字符串、数字、布尔值的基本使用；
- f-string 格式化输出；
- 字符串方法：`strip()`、`lower()`、`title()`、`replace()`；
- 把多项信息组织成一份 Markdown 学习日报。

## 为什么对 AI/RAG/Python 实习有用

以后你会经常生成日志、Prompt、README、实验报告和 API 调试输出。格式化文本能力看起来基础，但它是写清楚程序输出、调试信息和项目报告的第一步。

## 今天必须掌握的概念

- 变量保存数据；
- 字符串可以拼接和格式化；
- 数字可以做计算和格式化；
- 输出应该结构化，方便人阅读。
