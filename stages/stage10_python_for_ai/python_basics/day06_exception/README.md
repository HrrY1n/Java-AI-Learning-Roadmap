# day06：异常处理与健壮代码

## 今天学什么

- `try/except`；
- `FileNotFoundError`；
- `json.JSONDecodeError`；
- 空输入检查；
- 数字转换错误；
- 让程序给出友好提示。

## 为什么对 AI/RAG/Python 实习有用

真实项目里，文件可能不存在，JSON 可能格式错误，用户输入可能为空，API 返回可能缺字段。会处理异常，程序才不会一遇到问题就崩。
