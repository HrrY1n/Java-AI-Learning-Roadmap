# 预测与修改练习：答案

**先完成 [predict_and_modify.md](predict_and_modify.md) 至少 6 题再打开本文件。** 预测错误的条目，重点读"为什么"而不是背结果。

## A1
```text
3 / 1
3.5
```
为什么：`7 / 2` 两个 int → 商 3 舍余；`7 % 2` 余 1。`7 / 2.0` 有 double 参与 → 小数除法。

## A2
```text
3345
```
为什么：从左到右——`1+2` 是 int 加法得 3；再遇 `"3"` 变拼接得 `"33"`；之后全是字符串拼接。

## A3
```text
012
```
改 `<=` 后：
```text
0123
```
为什么：`i < 3` 最后一轮 i=2；`i <= 3` 最后一轮 i=3。

## A4
```text
1 3 结束
```
为什么：偶数被 continue 跳过；i=5 时 break 直接终止循环——"结束"由循环后的 println 打出。continue 不会跳过 `i++`。

## A5
```text
99
```
为什么：`b = a` 复制的是数组地址，两个变量是同一段格子的两个名字。

## A6
```text

```
为什么：值传递。`bump` 里的 x 是副本，自增与外面无关。

## A7
```text
66
B
```
为什么：`'A' + 1` 参与算术时 char 被提升为 int（65+1=66）；强转回 char 后按字符表解读为 B。

## A8
```text
安全
```
`&&` 左边为 false 时右边**不执行**（短路），所以右边那个 `score / 0` ——一个一旦执行就必然崩溃的除法——根本没发生。换成 `&`：两个操作数都会执行 → 抛 `ArithmeticException: / by zero`。这就是为什么条件判断用 `&&`/`||` 而不用单个 `&`/`|`：短路求值天然挡住"右边危险"的写法。

## A9
```text
-2147483648
```
不报错，也不变大——int 是 32 位补码格子，最大值加 1 绕回最小值。这就是溢出：数学上的意外，类型系统的"正常行为"。需要更大范围就换 long（字面量加 L）；两个 int 相乘前先想量级，必要时先转 long 再乘。

## B1
五行全部变化（b 成为 double 后，含 b 的运算全部走浮点）：
```text
a + b = 13.0
a - b = 7.0
a * b = 30.0
a / b = 3.3333333333333335
a % b = 1.0
```
对比原版 `13 / 7 / 30 / 3 / 1`：加、减、乘和取余只是**显示**成小数（值没变，1 仍显示 1.0），真正**值变了**的只有除法（3 → 3.3333333333333335）。注意它结尾是 5 不是 3——double 用二进制存小数，10.0 / 3.0 在第 17 位有效数字处按舍入截断，这是表示方式的正常行为，不是打印错误。后面的"价格/是否成年/等级"行不含 b，不变。

## B2
90 → 60：按 day05 当前数据 {90,85,76,100}，总分 351 → 321（减少 30）；平均分 87.75 → 80.25（减少 30/4 = 7.5）。笔算后与运行一致才通过。

## B3
把 `return;` 换成 `break;` 后：输入 0 → 打印"程序结束。"→ `break` 只跳出 switch → 回到 while → **再次打印菜单并等待下一次输入**。此时 `scanner` 已被 `close()` 关闭，下一次 `nextInt()` 会抛 `IllegalStateException`——程序不是"不再退出"，而是"退出逻辑失效后崩溃"。两个关键点：`break` 跳出的是 switch，不是 while；原版用 `return` 直接结束 main。顺带记住：包住 `System.in` 的 Scanner 不要在循环内关闭。

## B4
