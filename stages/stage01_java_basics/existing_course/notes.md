# Stage01 笔记：Java 基础语法

## 程序入口

Java 程序从 `main` 方法开始执行：

```java
public static void main(String[] args) {
}
```

初学阶段先记住：如果一个类要直接运行，通常需要写 `main` 方法。运行命令 `java 类名` 时，JVM 会寻找这个入口。

## 变量和数据类型

变量用于保存数据。常见类型：

- `int`：整数，例如年龄、数量。
- `double`：小数，例如价格、平均分。
- `boolean`：真假值，例如是否登录。
- `char`：单个字符。
- `String`：字符串，例如姓名、标题。

后端项目中，变量常用于保存请求参数、数据库查询结果、业务计算结果。

## 判断

`if` 用于处理条件分支：

```java
if (score >= 60) {
    System.out.println("及格");
} else {
    System.out.println("不及格");
}
```

真实项目中，判断常用于校验参数、判断登录状态、判断库存是否足够。

## 循环

循环用于重复执行代码。`for` 适合次数明确的场景，`while` 适合条件满足就继续的场景。

菜单程序通常使用 `while (true)`，并在用户选择退出时用 `break` 结束。

## 数组

数组用于保存一组相同类型的数据。数组长度固定，下标从 0 开始。

初学阶段可以用数组保存分数；后面会用 `List` 替代数组，管理数量可变的对象。

## 方法

方法用于封装一段可重复使用的逻辑：

```java
public static int add(int a, int b) {
    return a + b;
}
```

后端项目里，Controller、Service、Mapper 都是通过方法互相调用完成业务流程。

## 调试思路

遇到错误时不要只盯着最后一行。建议顺序：

1. 看报错的文件名和行号。
2. 看错误类型，例如 `cannot find symbol`。
3. 检查大小写、分号、括号、类名和文件名。
4. 如果程序能运行但结果不对，打印关键变量。
