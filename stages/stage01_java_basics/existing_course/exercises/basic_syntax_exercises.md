## 练习 1：成绩统计

**任务背景**：老师给你一份期末成绩单，需要一份包含总分、平均分、最高/最低分、及格人数的报告。

- **输入**：写死的 `int[]`，至少含 5 个分数（0~100）。不要用 Scanner。
- **输出**：五行，形如 `总分：402`、`平均分：80.4`、`最高分：100`、`最低分：55`、`及格人数：4`。
- **约束**：平均分必须带小数（用 `* 1.0` 或等价手段）；求和/求最值/计数各写成独立方法。

**示例（正常）**：`{88, 92, 67, 100, 55}` → 平均分 80.4，及格 4 人。
**边界示例**：`{100}`（单元素）→ 四个统计值都是它本身，及格 1 人。
**错误输入（必须处理）**：`{}`（空数组）→ 不崩溃，打印 `暂无成绩数据` 并正常结束。思考：max 初始化为 0 为什么在空数组之外还会出错（全负数场景见 [深化课 03](../../deep_dives/03_array_memory/README.md)）？

**验收条件（全部满足才算完成）**
- [ ] 示例、单元素、空数组三组输入的输出都符合预期（亲自运行三遍）。
- [ ] 不看旧答案能解释：为什么平均分要 `* 1.0`；max/min 为什么初始化为 `scores[0]`。
- [ ] 每个方法一句话能说清职责（[深化课 06](../../deep_dives/06_method_scope/README.md) 的一句话测试）。

**需要独立思考的部分**：空数组的判断放在 main 还是统计方法里？两种写法的利弊（不要求唯一答案，要求能说理由）。

## 练习 2：简单计算器

**任务背景**：给初学者做一个四则运算命令行工具。

- **输入**（Scanner，按顺序）：第一个数（double）、运算符（`+ - * /` 之一）、第二个数（double）。
- **输出**：`结果：2.0` 这样的单行；非法情况输出对应提示并**正常结束**（退出码 0）。
- **约束**：除数为 0 必须提示；运算符不在支持列表必须提示；非数字输入**不崩溃**（用 [深化课 07](../../deep_dives/07_scanner_input/README.md) 的防御模式）。

**示例（正常）**：输入 `6` `/` `3` → `结果：2.0`；输入 `7` `%` `2` → `暂不支持这个运算符：%`。
**边界示例**：输入 `0.1` `+` `0.2` → 结果不是精确的 0.3（浮点误差，打印即可，在注释里写一句为什么）。
**错误输入（必须处理）**：`abc` `+` `3` → 提示"请输入数字"并不崩溃；`5` `/` `0` → `除数不能为 0`。

**验收条件**
- [ ] 三组正常 + 两组错误输入各运行一遍，行为全部符合预期。
- [ ] 非法输入后程序**不会**继续用残缺数据做计算。
- [ ] 能解释：为什么除法分支要在运算前判断 `b == 0`，而不是捕获 `ArithmeticException`（double 除零不抛异常，想想会输出什么）。

**需要独立思考的部分**：运算符分发用 if-else 链还是 switch？两种都行，写出你的选择理由。

## 练习 3：循环菜单

**任务背景**：交互式程序的骨架——Stage 01/02 的小项目全部长这个样子。

- **输出**：循环打印菜单（1 打招呼 / 2 查看学习目标 / 0 退出）。
- **约束**：非法菜单项提示并**回到菜单**（不是退出）；`0` 退出时打印结束语；非数字输入不崩溃（同练习 2 的防御）。

**示例（正常会话）**：`1` → 打招呼；`9` → `没有这个选项，请重新输入` 并回菜单；`0` → `程序结束。`
**错误输入（必须处理）**：`abc` → 提示非法后回菜单，程序不崩溃、不卡死。

**验收条件**
- [ ] 完整会话演示：两次正常操作 + 一次非法数字 + 一次非数字 + 退出。
- [ ] 把上面会话的输入存成文本，用重定向跑一遍仍正确：`java -cp out 你的FQCN < input.txt`（这就是 [scripts/fixtures](../../../../scripts/README.md) 的工作方式）。
- [ ] 循环条件、break 位置与 [深化课 05](../../deep_dives/05_loop_bounds/README.md) 的"三问答"一致。

**需要独立思考的部分**：用 `while (true) + break` 还是用布尔变量控制循环？说明取舍。

## 练习 4：方法拆分（重构练习）

**任务背景**：把练习 1 的"每个统计一个方法"升级为一次小型重构训练。

- **任务**：先写一个"全塞在 main 里"的版本（故意写乱：重复循环、魔法数字 60）；然后重构为方法版。两版输出必须完全一致。
- **验收条件**
  - [ ] 重构前后对同一组数据的输出**逐字符一致**（这是重构的定义）。
  - [ ] main 只剩流程编排（≤10 行）。
  - [ ] 能说出"及格线 60 改成 70"在两版里分别要改几处——并解释这个数字为什么是拆分质量的度量。

**需要独立思考的部分**：哪个方法应该知道"及格线"这个概念？把它做成参数、常量还是留死？写一句理由。

## 渐进提示（卡住才看，逐级解锁）

### 练习 1
- **L1 理解问题**：你要对同一组数据做五次不同角度的汇总；先把"遍历一次能同时算出几个统计值"想清楚。
- **L2 相关知识**：求最值的初始化见 [深化课 03](../../deep_dives/03_array_memory/README.md) 常见错误节；空数组判断 `scores.length == 0`。
- **L3 结构思路**：main 里：判空 → 调用 calculateTotal/findMax/findMin/countPass → 组装输出。每个方法只遍历、只返回。
- **L4 调试线索**：结果全为 0 → 检查 return 是否漏写；平均分没有小数 → 回看整数除法深化课；空数组报越界 → 判断放的位置不对。

### 练习 2
- **L1**：一次会话读三个输入；三种非法情况都要"提示后体面结束"。
- **L2**：Scanner 防御模式见深化课 07 的 readIntInRange——你需要一个 double 版。
- **L3**：读数（循环直到合法）→ 读运算符 → 读数 → 分发 → 输出。
- **L4**：`0.1+0.2` 输出 `0.30000000000000004` 属正常浮点现象；除法输出 `Infinity` 说明你忘了判零。

### 练习 3
- **L1**：菜单循环 = 打印 → 读 → 分发 →（未退出则）再来一轮。
- **L2**：非数字输入的"崩溃循环"机制见深化课 07 开头；修复靠消费坏记号。
- **L3**：把"读一个 0~2 的合法选项"提炼成方法，菜单循环体只剩分发。
- **L4**：重定向测试卡死 → 你的循环在输入耗尽后还在等；输入顺序与提示不对应 → 多读或漏读了换行。

### 练习 4
- **L1**：重构 = 改内部结构不改行为；先冻结"正确输出现场"再动手。
- **L2**：一句话测试与三个检查见深化课 06。
- **L3**：按统计种类切方法；60 抽成 `PASS_LINE` 常量；对比两版改动点数量。
- **L4**：两版输出不一致 → 说明重构改了行为，回到"哪一步语义变了"逐方法比对。
