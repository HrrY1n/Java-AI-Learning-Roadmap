# Java 基础语法练习

## 输出与变量

1. 输出你的姓名、年龄、学校或城市。
2. 定义两个整数变量，输出它们的和、差、积。
3. 定义一个商品价格和购买数量，计算总价。

## 判断

1. 给定一个年龄，判断是否成年。
2. 给定一个分数，输出优秀、良好、及格、不及格。
3. 给定一个月份数字，输出它属于哪个季节。

## 循环

1. 输出 1 到 100。
2. 计算 1 到 100 的和。
3. 输出 1 到 100 中所有偶数。

## 数组

1. 定义一个分数数组，输出所有分数。
2. 求数组最大值。
3. 求数组平均值。

## 方法

1. 写一个方法，接收两个整数并返回和。
2. 写一个方法，判断一个整数是否为偶数。
3. 写一个方法，接收姓名并输出欢迎语。
