# answers/ 目录说明

参考实现与复现场景材料。使用纪律（教学协作细则）：

- **先自己完整尝试任务，再对照本目录**。参考实现是"可复现的对照物"，不是抄写目标。
- task3/task6/task8 的 broken 文件是**故意写错的复现场景**——按任务书步骤先复现失败，再修复。
- 复现参考实现时请在自己的 `my_practices/` 副本中操作；不要直接修改 `stages/` 下的正式工程。

| --- | --- | --- |

| task6-broken.md | 任务 6 状态码 | 状态码全错的坏 Controller |

| task8-broken.md | 任务 8 依赖冲突 | 制造/解决依赖冲突的操作脚本 |
