# 集合与泛型练习（每日小题库）

随堂小练习：每个主题挑 1–2 题。**验收标准：编译运行通过 + 能说出选择该结构的理由**（"怎么访问数据就选什么"，见 [集合选择深化课](deep_dives/01_choose_collection/README.md)）。结构化的综合练习见 [existing_course/exercises](existing_course/exercises/collection_exception_io_exercises.md)。做完的代码放 `my_practices/`（Stage 03 下）。

## ArrayList

1. 使用 ArrayList 保存 5 个城市名。
2. 删除其中一个城市并输出列表。
3. 判断列表中是否包含某个城市。

## HashMap

1. 使用 HashMap 保存商品名和价格。
2. 根据商品名查询价格。
3. 修改一个商品的价格。

## HashSet

1. 使用 HashSet 保存多个手机号，观察重复值。
2. 判断某个手机号是否存在。
3. 删除一个手机号。

## 泛型

1. 创建 `Box<String>` 保存一本书名。
2. 创建 `Box<Integer>` 保存一个分数。
3. 思考为什么 `Box<String>` 不能保存整数。

## 综合

1. 使用 `ArrayList<Student>` 保存学生列表。
2. 找出分数大于 90 的学生。
3. 计算所有学生的平均分。
