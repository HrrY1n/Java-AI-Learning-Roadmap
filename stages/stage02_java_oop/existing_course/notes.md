# Stage02 笔记：面向对象

## 类和对象

类是模板，对象是根据模板创建出来的具体数据。

例如 `Student` 是类，`new Student(1, "小明", 90)` 创建出来的是一个具体学生对象。

## 构造器

构造器用于创建对象时初始化关键数据。构造器名字必须和类名一致，没有返回值。

后端项目中的 Entity、DTO、VO 都是类，很多时候会通过构造器或 setter 填充数据。

## 封装

封装就是把字段设为 `private`，通过方法控制外部如何访问数据。

例如账户余额不能随便改，必须通过 `deposit` 和 `withdraw` 方法修改。这样可以把“余额不能为负数”这样的规则放在类内部。

## 服务类

本阶段新增了 `StudentService`、`LibraryService`、`BankService`。它们的作用是保存业务操作，例如添加学生、借书、存钱。

这会为后面的 Spring Boot 做铺垫。以后真实项目中，Controller 接收请求，Service 处理业务，Mapper 访问数据库。

## 继承和多态

继承表示“是什么”的关系，多态表示“同一个父类引用可以指向不同子类对象”。本阶段旧 day 示例已经展示了 Animal、Dog、Cat。

项目里不必为了使用继承而使用继承。优先把类职责设计清楚，继承只在确实存在共同父类时使用。

## 接口和抽象类

接口表示能力或规则，抽象类表示不完整的父类模板。后面 MyBatis 的 Mapper、Spring 的 Service 接口，都会大量使用接口思想。
