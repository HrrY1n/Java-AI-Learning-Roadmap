# 深化课 02：构造方法与 this——对象如何带着合法状态出生

对应示例：`com/javaroadmap/stage02/deepdives/constructorthis/ConstructorThisDemo.java`

**运行后你会看到什么**：多次 `姓名：…，年龄：…`（包含委托构造器与链式调用）；取消注释的非法构造会抛 `IllegalArgumentException`。看完本文你应该能按 JLS 说清 `new` 一步背后完整的初始化顺序，以及 `this` 的四种准确用法。

## 场景

day02 的写法是 `new Person("小明", 18)`——如果没有构造器，`new Person()` + 逐字段赋值的写法允许"先造出一个 name=null 的半成品"，任何人在半成品上调用方法都会出错。**构造器把"对象从一开始就完整、合法"变成类的责任，而不是每个使用者的自觉**。

## 必须理解

### 1. `new Person("小明", 18)` 依次发生什么（JLS §12.5）

1. 在堆上分配对象内存，所有实例字段先赋予**零值/默认值**（数值为 `0`、`boolean` 为 `false`、引用为 `null`）；
2. 隐式或显式调用**父类构造器 `super(...)`**（哪怕你没手写 `extends`，也会自动追溯到 `Object`）；
3. 按源码顺序执行**本类的实例字段显式初始化**（例如 `int grade = 1;`）与**实例初始化块**；
4. 执行**匹配的本类构造器方法体**（参数校验、`this.name = name` 等）；
5. 把新对象的引用返回给调用方变量（结合上一课：赋给变量的是引用）。

### 2. 默认构造器与消失规则（JLS §8.8.9）

**没有写任何构造器时**，编译器自动生成一个无参构造器：它的访问修饰符**与当前类一致**（类是 `public` 它就是 `public`，包私有它也包私有），且内部并非“什么都不做”——它会隐式执行 `super()` 完成父类部分初始化。

**一旦你显式写了任何构造器**，编译器**不再提供**默认无参构造器——这就是"写了有参构造器后 `new Person()` 编译报错"的原因。需要无参构造时，必须自己补写。

### 3. `this` 的全部四种常见用法

`this` 是“当前正在执行/初始化的那个对象实例的引用”。日常高频有四种用法：

1. **解决名称遮蔽**：`this.name = name`（左字段、右参数）；
2. **明确操作当前调用者**：`this.rename(...)` 或访问当前对象的另一成员；
3. **构造器间委托**：`this(name, 18)`——必须放在构造器第一行（且不能和 `super(...)` 同时出现），把校验逻辑收拢在一个主构造器里；
4. **返回或传递自身**：`return this;` 用于链式调用（如 Builder 模式），或 `register(this)` 把当前对象传给外部组件。

**常见初级大坑**：在构造器上不小心加了返回值类型 `public void Person(...)`——这**不是构造器**，而是名字恰巧与类名相同的普通方法，编译器不会帮你做 `new` 时的初始化！

## 理解原理：为什么把关要在构造器里

对象一旦出生，它的字段可能被持有引用的代码修改（上一课的别名问题）。**把关越靠近出生时刻，非法状态存活的时间越短**。构造器校验是"防御的最早时机"；彻底的控制要到下一课封装（`private` 字段）才能实现——那时所有修改入口都被收拢，校验才真正无法绕过。

**Observe（先预测再运行）**：① 注释掉构造器里 age 校验那三行，取消 main 非法构造段的注释——输出什么？② 恢复校验再运行——报错发生在 `new` 这一行还是 `show()` 这一行？先预测再验证，这能检验你是否真的理解"构造在 new 时执行"。

2. 把字段 `int age` 改成 `Integer age` 再新建对象并**在构造器赋值前打印它**：观察引用默认值 `null` 与基本类型默认值 `0` 的区别。

## 常见错误

- 写了有参构造器却还想要无参用法：需要就显式再写一个无参构造器（如框架反序列化常需要无参构造器）。
- 误写 `public void Person(...)`：加了 `void` 就变成普通方法，编译器连警告都不一定有，直接跳过初始化！
- `this.name = name` 写成 `name = name`：参数给自己赋值，字段仍是 `null`——不报错但完全无效。
- 在构造器里做重活（IO、线程启动、复杂计算）：尤其不能在构造完成前把 `this` 发布给其他线程（泄漏未完全初始化对象）。

## 独立练习

在 `my_practices/` 写一个 `Rectangle` 类：两个构造器（宽高双参 / 只给宽=正方形委托到双参构造器），校验边长必须 > 0（否则抛 `IllegalArgumentException`），提供 `area()`、`perimeter()`、`show()`。自检：`new Rectangle(3, 4)` 面积 12；`new Rectangle(5)` 面积 25；`new Rectangle(-1)` 抛异常；`new Rectangle()` 编译失败并解释原因。
